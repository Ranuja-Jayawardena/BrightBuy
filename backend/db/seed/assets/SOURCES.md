# Seed product image sources

These are representative demo photographs for fictional BrightBuy products. They do not depict or endorse the named BrightBuy brands or specifications.
For IDs 17–21, 24–30, 34–35, and 37, each `primary.webp` is a square presentation of the source photograph; `secondary.webp` is a tighter feature crop of that same photograph. Both are adaptations of the linked source.
Attribution and license terms below must be retained wherever these files are published. Check the linked license before reuse outside this project.

IDs **1–16, 22–23, 31–33, 36, and 38–40** use AI-generated, unbranded demo product imagery created with the built-in image generation tool on 2026-10-13. Their secondary views are feature crops of the same generated image. They are illustrative only and do not document the exact appearance of the fictional product or its advertised specifications.
